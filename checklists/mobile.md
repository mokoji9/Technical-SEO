# Checklist: Mobile-Friendliness

- [ ] Viewport meta tag is present and correct (`width=device-width, initial-scale=1`)
- [ ] Site passes Google's Mobile-Friendly Test
- [ ] Text is readable without zooming (minimum ~16px body text)
- [ ] Tap targets (buttons/links) are large enough and not too close together
- [ ] No horizontal scrolling / content doesn't overflow the viewport
- [ ] Mobile page speed is on par with desktop (Google uses mobile-first indexing)
- [ ] No intrusive interstitials/pop-ups blocking mobile content
- [ ] Mobile and desktop content match (same content served both ways)
- [ ] Structured data present on mobile version too
