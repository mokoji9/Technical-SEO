# Checklist: Site Architecture

- [ ] URLs are short, descriptive, and human-readable (no long ID strings if avoidable)
- [ ] URL structure is consistent (lowercase, hyphens not underscores)
- [ ] Logical hierarchy (category → subcategory → page), reflected in the URL path
- [ ] Important pages are within 3 clicks of the homepage
- [ ] Internal linking supports key/priority pages (not just footer/nav links)
- [ ] No broken internal links (404s)
- [ ] Pagination doesn't create deep, hard-to-crawl chains
- [ ] Breadcrumbs are implemented (and marked up with schema)
- [ ] XML sitemap and internal links stay in sync with site structure
- [ ] No excessive/unnecessary subdomains splitting authority
