# Checklist: Structured Data (Schema Markup)

- [ ] Structured data is present for the page type (Article, Product, FAQ, LocalBusiness, etc.)
- [ ] Markup passes Google's Rich Results Test with no errors
- [ ] No warnings for missing recommended fields
- [ ] JSON-LD format is used (Google's preferred format)
- [ ] Structured data matches the visible content on the page (no mismatched/fake data)
- [ ] Organization/website schema present sitewide (helps brand knowledge panel)
- [ ] Breadcrumb schema matches actual site navigation
- [ ] No deprecated schema types in use
